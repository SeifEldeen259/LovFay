# For Zozo ♡

A cinematic, interactive love story made especially for Zozo—filled with memories, playful moments, heartfelt surprises, and our favorite song.

## Features

- Mobile-first romantic experience with smooth transitions and floating hearts
- A playful question screen with an impossible-to-click “Yes” button
- Swipeable memory gallery with 3D card flips and full stories
- Animated final letter, confetti, sparkles, and hidden Easter eggs
- Background music support

## Project structure

```text
index.html
style.css
script.js
/images
/music
```

## Run locally

Open `index.html` in any modern browser.

## Add or edit memories

At the top of `script.js`, edit the `CONFIG` object to update the music path, final letter, photo order, titles, messages, and stories.

## GitHub Pages

1. Keep `index.html`, `style.css`, and `script.js` in the repository root.
2. Keep photos in `images/` and the MP3 in `music/`.
3. In **Settings → Pages**, select **Deploy from a branch**, then choose **main** and **/(root)**.
4. Save and wait for GitHub Pages to publish the site.
